獨立 API 測試保留原有課程、員工、報名、完訓、刪除關聯限制、輸入驗證、統計變化及兩人同時搶最後名額等核心驗證。新增測試包含：匿名管理 API 401、不完整登入 400、錯誤帳密 401、有效 JWT claims／期限／使用者、變造簽章、錯誤 issuer、錯誤 audience、過期 JWT、登出撤銷兩個工作階段，以及重新登入的 TokenVersion 更新。

註冊新增的獨立 SQL Server 驗證涵蓋欄位規則、拒絕自行指定角色、重複與同時註冊、密碼雜湊、一般使用者登入及管理寫入權限。新流程驗證管理員為待處理帳號建立獨立員工、缺少欄位與重複編號遭拒、重複建立遭拒，以及帳號 JWT 在建立後即取得員工身分，並可報名和取消。目前日常資料庫仍保留既有資料；測試不修改日常資料庫。

測試使用本次隨機建立的 `TrainingManagement_Test_<GUID>` SQL Server 資料庫，Windows 驗證連線。測試成功後僅清理本次建立的資料庫及 5081 測試程序，日常 `TrainingManagement` 資料庫保留。

第一版另已完成瀏覽器新增員工、課程、報名、完訓、員工編輯、中文 CSV 實際下載與 UTF-8 BOM 檢查、手機管理表格及重新啟動保存的操作驗證。本次資料庫切換後，核心業務流程重新由真實 SQL Server 整合測試驗證，瀏覽器重新驗收登入與既有資料顯示。

目前提供管理員與一般使用者角色，以及管理員註冊帳號清單與新員工建立介面。正式部署、多部門分級權限、SSO 與稽核功能不在本次驗證範圍。帳號清單、報名與取消畫面已通過 Angular 編譯及 API 整合測試；此版本尚未完成瀏覽器端實際點擊驗收。
